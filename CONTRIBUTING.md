# Contributing to shree-agent-cli

## Code Quality

- All code must pass ESLint and Prettier checks before commit.
- Pre-commit hook will automatically run `npm run lint` and `npm run format`.
- Use `npm run lint` to check for lint errors.
- Use `npm run format` to auto-format code with Prettier.

## Commit Messages

- All commits must follow the Conventional Commits standard.
- Commit messages are checked by commitlint.

## Release Process

- Versioning and changelog are managed by semantic-release.

## Setup

1. Run `npm install` to install dependencies and set up Husky hooks.
2. Use `npm run lint` and `npm run format` before pushing changes.

## Questions?

Open an issue or contact the maintainer.
